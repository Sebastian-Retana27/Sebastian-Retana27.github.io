# Portfolio en React

## Requisitos
- Node.js 18+

## Ejecutar en desarrollo
```bash
npm install
npm run dev
```

## Build de producción
```bash
npm run build
npm run preview
```

## Personalización rápida
- Cambia tu nombre, correo y textos en `src/App.jsx`.
- Ajusta colores y tipografías en `src/styles.css`.
